po0-clash v5.3.0：桌面端整体改为更简洁的 Clash Verge 风格，重做代理组列表、设置子页面和延迟测速入口。

## 本次更新

- Windows / macOS 桌面端整体视觉改为 Clash Verge 风格：浅灰工作区、白色内容卡片、蓝色强调色、更紧凑的圆角与间距，减少移动端和玻璃拟态感
- 保留现有左侧主菜单结构，连接控制、代理模式、虚拟网卡 / 系统代理开关改为更紧凑的桌面布局
- 代理页改为纵向策略组列表：策略组整行展示，展开后直接显示节点网格，更适合节点和策略组较多的配置
- 节点选中态改为淡蓝背景与左侧蓝色指示条，协议标签、延迟信息和节点卡片层级重新整理
- 恢复代理页右上角全局一键延迟测试，可一次测试当前配置中的全部节点
- 每个策略组右侧新增独立延迟测速按钮，布局为“节点数量 → 延迟测速 → 展开/收起”，不再单独占用一行工具栏
- 设置页二级页面在桌面端改为占满右侧工作区，左侧主菜单保持可见，不再使用窄侧边抽屉
- 语言等选择器改为桌面单选弹窗，统一标题、圆形单选项、间距、边框和圆角
- 桌面顶部工具栏、弹窗、设置卡片、图标与状态颜色统一调整，默认强调色更新为 #1677FF
- 保留原有 Mihomo Core、po0 自动加白、配置与节点切换逻辑，本次主要重构桌面交互与视觉层

## 升级说明

- 可从 5.2.1 直接覆盖安装，现有配置和 po0 设置继续保留
- 本次桌面 UI 改动较大，Android 仍以现有移动端布局为主
- 已保存的自定义主题色保持原设置；默认主题使用新的桌面蓝色强调风格

## 安装

- Windows：po0-clash-5.3.0-windows-amd64-setup.exe（安装包）或 .zip（免安装）
- macOS：使用 Release 中对应架构的 dmg，或运行仓库 scripts/install-macos.sh
- Android：po0-clash-5.3.0-android-arm64-v8a.apk（主流机型），可与官方 FlClash 共存

## 已知限制

- Android 首次开启自动加白后需重启一次 VPN，直连路由才会生效
- Android 从最近任务划掉 po0-clash 后停止检查，重新打开应用即恢复
- 同时在用的网段超过白名单容量（5 条，服务端已有的固定记录也占名额）时，各设备会互相挤占
- 与其他代理客户端同时开启系统代理或 TUN 会互相抢占，请只在一个应用里开启
- macOS 版本未经 Apple 公证，首次启动时可能需要按系统提示允许运行

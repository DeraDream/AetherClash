AetherClash v5.5.9：重做活动连接页，修复网络信息页面层级，并完善桌面升级后的代理状态恢复。

## 本次更新

- 活动 → 连接按 Clash Party 的实时连接逻辑重做
  - 移除独立 Requests 页面，连接与已关闭历史统一到 Connections
  - Core 新连接事件会立即唤醒刷新，同时保留 500ms 轮询计算实时上传 / 下载速度
  - 支持活动 / 已关闭切换
  - 已消失连接自动进入已关闭列表
  - 支持按时间、上传量、下载量、上传速度、下载速度排序
  - 支持关闭当前匹配连接、单独断开连接和删除已关闭记录
  - 搜索覆盖主机、进程、来源 / 目标 IP 与端口、规则、规则内容、代理链等字段
  - 修复实时刷新时搜索框和搜索内容被重置的问题

- 修复 Activity 页面切换
  - Connections / Logs 切换后旧页面立即销毁
  - 不再因为过渡动画短暂保留两个 ConnectionsView
  - 避免重复 Core 轮询和瞬时重复连接视图

- 网络信息改为真正独立的桌面工作区页面
  - App 首次启动后可直接点击左下角网络信息
  - 不再依赖先进入设置或其他页面
  - 打开网络信息不会改变当前左侧主菜单页面
  - 从网络信息切回设置 / 其他页面时层级与点击状态正常

- 桌面升级状态恢复
  - 升级安装前保存当前运行状态、系统代理和 TUN 状态
  - 新版本首次启动后一次性恢复升级前状态
  - 恢复标记有时效限制，避免旧状态误恢复
  - 手动退出 App 仍会清除系统代理和 TUN
  - 更新流程退出不会提前清除代理状态

- 发布前回归
  - Dart formatting / parsing 通过
  - Flutter Analyze 通过
  - 完整 Flutter tests 通过
  - 新增搜索持续刷新、Activity 单实例、网络信息独立页面、升级状态恢复与手动退出清理测试

## 发布目标

- Windows amd64
- macOS arm64

Android 与 macOS Intel 继续暂时停用，相关构建代码仍保留。

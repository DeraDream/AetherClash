AetherClash v5.5.10：活动连接页改为 Clash Party 式实时表格，并修复网络信息页面透出底层工作区的问题。

## 本次更新

- 活动 → 连接改为 Clash Party 式表格
  - 活动中 / 已关闭双 Tab，并显示各自数量
  - 搜索框常驻顶部，支持搜索完整连接信息
  - 表格列包含状态、连接建立时间、连接类型、主机、进程、规则、代理链、上传 / 下载速度、上传 / 下载量、远程目标
  - 每个表头都可直接点击排序
  - 新选择的排序列默认降序，再次点击切换为升序
  - 默认按连接建立时间降序，最新连接优先显示
  - 下载速度等数值列可直接把高流量连接排在顶部

- Clash Party 式实时追踪控制
  - 右上角支持暂停 / 继续实时连接追踪
  - 暂停期间停止 500ms 连接快照轮询，同时忽略新请求即时刷新
  - 恢复后立即重新读取当前连接
  - 恢复时重置速度计算基线，避免把暂停期间累计流量错误显示成瞬时高速
  - 右上角支持清除当前连接 / 已关闭历史
  - 有搜索条件时只操作当前匹配结果

- 表格交互
  - 支持显示 / 隐藏列，并至少保留一列
  - 支持拖动表头边界调整列宽
  - 列较多时使用横向滚动，纵向连接列表保持懒加载
  - 单行仍可打开连接详情
  - 活动连接可单独断开，已关闭记录可单独删除

- 网络信息页面层级修复
  - 打开网络信息时底层原工作区改为 Offstage
  - 原页面状态继续保留，但不再绘制、响应点击或接收焦点
  - 修复网络信息底部透出活动页 / 设置页内容的问题
  - 关闭网络信息后原工作区可正常恢复

- 发布前回归
  - Dart formatting / parsing 通过
  - Flutter Analyze 通过
  - 完整 Flutter tests 通过
  - 表头排序、下载速度排序、暂停 / 恢复、搜索、懒加载表格与网络信息独立显示均有回归覆盖

## 发布目标

- Windows amd64
- macOS arm64

Android 与 macOS Intel 继续暂时停用，相关构建代码仍保留。

po0-clash v5.5.0：修复 Windows 应用内升级未实际安装/重启的问题，并新增独立“内核”主页面。

## 本次更新

- 修复 Windows 在线升级下载完成后应用退出，但安装器未可靠接管、手动打开后版本仍未变化的问题
- Windows 更新流程改为先请求管理员权限并等待更新器 ready 握手，确认更新器已经接管后才关闭 po0-clash
- 取消 UAC 或管理员更新进程未成功启动时，当前 po0-clash 不再退出，而是直接显示错误
- 安装器在管理员更新进程内执行，安装成功后校验 po0-clash.exe 存在并自动重新启动
- Windows 更新日志保存到 %LOCALAPPDATA%\po0-clash\update.log，方便后续定位安装失败原因
- 移除左上角 po0-clash 标题旁的“已连接 / 连接中 / 已断开”内核状态，避免与代理连接状态混淆
- 新增独立“内核”主菜单，侧栏在“内核”菜单下明确显示当前内核状态
- 新增内核管理页面：展示 Po0ClashCore 状态、随客户端发布的兼容版本、内核文件位置和 SHA-256，并提供启动 / 重启与检查更新入口
- 内核与 Helper 的 IPC 和 SHA-256 校验是成套发布的，因此不直接提供任意官方 Mihomo 二进制切换；兼容内核版本随 po0-clash 版本一起升级
- 保留 v5.4.1 的 Windows 桌面快捷方式修复

## 升级说明

- Windows 5.4.0 / 5.4.1 用户可直接在应用内升级到 5.5.0；下载完成后会先出现 UAC，确认后应用才会退出
- 如果取消 UAC，当前应用会继续运行，不会出现“退出后没安装”的情况
- 安装完成后 po0-clash 应自动重新启动并显示 5.5.0
- 现有配置、订阅、po0 设置和桌面偏好均会保留

## 安装

- Windows：po0-clash-5.5.0-windows-amd64-setup.exe（安装包）或 .zip（免安装）
- macOS：使用 Release 中对应架构的 dmg，或运行仓库 scripts/install-macos.sh
- Android：po0-clash-5.5.0-android-arm64-v8a.apk（主流机型）

## 已知限制

- Android 首次开启自动加白后需重启一次 VPN，直连路由才会生效
- Android 从最近任务划掉 po0-clash 后停止检查，重新打开应用即恢复
- 同时在用的网段超过白名单容量（5 条，服务端已有的固定记录也占名额）时，各设备会互相挤占
- 与其他代理客户端同时开启系统代理或 TUN 会互相抢占，请只在一个应用里开启
- macOS 版本未经 Apple 公证，首次启动时可能需要按系统提示允许运行
